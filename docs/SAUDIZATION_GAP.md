## 2) ما هو مفقود بالكامل (جوهر المخطّط)

1. **كتالوج القرارات كبيانات** (فئة → نسبة → عتبة عدد → حد راتب → شرط اعتماد → مراحل زمنية).
   غير موجود إطلاقاً — لا المبيعات ٦٠٪/٣+، ولا الفنية ٣٠٪/٥+، ولا المحاسبة ٤٠→٧٠٪، ولا المقصورة ١٠٠٪ (٦٩ مهنة)، ولا الصيدلة/الأسنان/الأشعة/التغذية/العلاج الطبيعي/المشتريات.
2. **`classifySaudization(inputs, catalog)`** — الدالة النقية: النسبة الفعلية من الأعداد ← الفجوة ← الحالة ← تكلفة الحلول الثلاثة ← الأوفر. **غير موجودة.**
3. **مدخلات `HRQ_*`** (سعودي/غير سعودي/محتسب لكل فئة). حالياً السعودة = رقم ٪ واحد يُطبع يدوياً — لا عدّ.
4. **شرط الاحتساب** (راتب دون الحد الأدنى → لا يُحتسب سعودياً). غير موجود.
5. **مخرجات** `KPI_SAUDIZATION_GAP` / `KPI_SAUDIZATION_STATUS` / `KPI_BEST_SOLUTION_COST` + **جدول العبور `HRQ_* → KPI_*`**. غير موجودة.
6. **التسلسل الإلزامي للمقصورة ١٠٠٪** (توظيف سعودي ورفع عقده أولاً، ثم تغيير مهنة غير السعودي) كخطوتين مترابطتين. غير موجود — **أخطر بند وظيفي**: بدونه يوصي المحرك بإجراء غير نظامي.
7. **تنبيه «القرار دخل مرحلة جديدة»** التلقائي للمنشآت المتأثرة (مثال: المحاسبة ٤٠٪→٥٠٪ أكتوبر ٢٠٢٦). غير موجود.
