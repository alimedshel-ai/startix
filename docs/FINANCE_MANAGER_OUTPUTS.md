**المستويات الخمسة:** 🔴 ٠–٢٠ غير ناضج · 🟠 ٢١–٤٠ ناشئ · 🟡 ٤١–٦٠ متوسّط · 🟢 ٦١–٨٠ ناضج · ⭐ ٨١–١٠٠ متقدّم.
