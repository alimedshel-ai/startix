## صفحة `DeptAuditPage` — `/{dept}/audit`
[client/src/components/dept/DeptAuditPage.tsx](../client/src/components/dept/DeptAuditPage.tsx)

**الغرض:** حاوية دورة التدقيق — بطاقة القيمة، ثم النتيجة والأدوات المفتوحة، أو المعالج (wizard).

**الحالات (٤ فروع):**
| الحالة | متى | العرض |
|--------|-----|-------|
| `loading` | تحميل الشركة/إنشاء القسم | بطاقة «جاري التحميل…» |
| `error` | لا شركة مرتبطة / فشل | بطاقة حمراء + زر «تشغيل تشخيص المدير» → `/manager/diagnostic` |
| `result` | يوجد تدقيق سابق | SavedAuditCard + UnlockedToolsCard + StrategicSnapshotCard + NextStepCard |
| `wizard` | لا يوجد تدقيق | DeptAuditWizard |

**الأزرار:**
- **توليد مؤشرات الأداء** (أعلى، في result) → `submitDeptSmart` → توست «تم توليد N مؤشر». يتعطّل أثناء التوليد.
- **أعِد التدقيق** (في SavedAuditCard) → `mode='wizard'`.

**بطاقة AuditValueCard** — عمودان: «ما تحصل عليه» (٤ بنود: درجة صحّة، درجة كل محور، منطقة الخطر، مقارنة سابقة) · «ما يفتح تلقائياً» (٤: 7S، ذكاء KPIs، تحليل الفجوة، الخطة الاستراتيجية).

**بطاقة UnlockedToolsCard** — فلتر مستوى الخطة (٣ أزرار toggle + «عرض الكلّ»):
- `⚙️ تشغيليّة (يوم/شهر)` · `🎯 تكتيكيّة (٣-١٢ شهر)` · `🔭 استراتيجيّة (١+ سنة)`
- الافتراضي مُشتقّ من `strategyPath` (يظهر ⭐). الأداة خارج الفلتر تبهت (opacity 0.6).

**٦ بطاقات أدوات** (كل واحدة فيها «لماذا فُتِحت الآن؟» + المستويات):
| # | الأداة | الوجهة | المستويات |
|---|--------|--------|-----------|
| 1 | 🎯 البيئة الداخليّة (7S) | `/internal-environment` | تكتيكي، استراتيجي |
| 2 | 🧠 ذكاء KPIs | `/manager/dept-smart` | تشغيلي، تكتيكي |
| 3 | 📐 تحليل الفجوة | `/manager/dept-gap` | تشغيلي، تكتيكي |
| 4 | 🌐 PESTEL للإدارة | `/manager/dept-pestel` | تكتيكي، استراتيجي |
| 5 | ⚔️ قوى بورتر الخمس | `/porter` | استراتيجي |
| 6 | 🗺️ الخطّة الاستراتيجيّة | `/manager/strategic-plan` | الثلاثة |

**بطاقة StrategicSnapshotCard** — حالة SWOT (`💪s · 🔻w · 🌱o · ⚠️t` + رابط) · بانر الميزانية (أخضر داخل الحد / أحمر عند التجاوز، تحذير لا حظر) · قائمة المبادرات (حتى ٦، مع شارة المستوى + التكلفة).

## مكوّن `DeptAuditWizard`
[client/src/components/dept/DeptAuditWizard.tsx](../client/src/components/dept/DeptAuditWizard.tsx)

**الحالات (٤):** `loading` · `no-questions` («لا توجد أسئلة متاحة») · `answering` · `result`.

**الأسئلة:** ١٢ سؤال (٨ للامتثال)، ٣ لكل محور. **المقياس ٤ نقاط لكل خيار:** `0` غير موجود · `1` جزئي/غير منتظم · `2` موجود وموثّق · `3` محسّن ومُقاس.

**٤ محاور بأوزان:** الحوكمة (سقف ٣٠) · المالية (٣٠) · الفريق (٢٠) · الرقمي (٢٠) = ١٠٠.

**التنقّل:** سؤال بشاشة + شريط تقدّم `(step+1)/total`. سطر «أجبت N · متبقي M». تذييل «الأقسام: حوكمة ٣ · مالية ٣ · فريق ٣ · رقمي ٣».

**الأزرار (٤):** السابق (يتعطّل عند step=0) · التالي/إرسال (يتعطّل بلا إجابة أو أثناء الإرسال) · إعادة التدقيق · طباعة (`window.print()`).

**المعادلة:** لكل محور `score = (raw / rawMax) × cap`؛ `healthPct = total ÷ 100`.
**منطقة الخطر** (`risk = 100 − healthPct`): 🟢 آمنة ≥٧٥ · 🟡 تحذير ٥٠–٧٤ · 🟠 خطر ٢٥–٤٩ · 🔴 حرجة <٢٥.
**يُخزّن:** `DeptAudit` (answers, scores, totalScore, healthPct) + تحديث `Department.auditScore/auditData`.
