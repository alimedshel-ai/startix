## §أ — جدول العتبات (القطعة المنتزَعة الآن للقمرة)

**تنبيه مصالحة:** الملف يبوّب **بعتبات نسبيّة متعدّدة لكل محور** (لا `maturity_score`
واحد كقمرة النموذج). ميكانيزمان مختلفان يجب عدم خلطهما:
- **توجيه المسار (routing):** قرار القمرة «إلى أين تالياً» — يمكن أن يعتمد نضجاً كلّيّاً.
- **فتح العمق (depth-unlock):** قرار الملف «هل تظهر أسئلة الدرجة ٢ لهذا المحور» — **لكل محور على حدة**.

### عتبات الدرجة ٢ (فتح العمق) — لكل محور
| محور الدرجة ١ | يفتح محور الدرجة ٢ | الشرط |
|---|---|---|
| الامتثال القانوني | الامتثال المتقدّم | النسبة < ٤٠٪ |
| البنية التحتية | البنية المتقدّمة | النسبة < ٤٠٪ |
| التكلفة والرواتب | التحليل المالي | النسبة < ٥٠٪ |
| الخطر المباشر | إدارة المخاطر | النسبة < ٣٠٪ (خطر مرتفع) |
| (أيّ محور) | خطة الطوارئ | أيّ محور < ٣٠٪ → **مراقبة** |

> **تنقيح ٢٠٢٦-٠٧-٢٢ (النسخة الثانية من الملف):** عتبة محور الخطر صُحّحت إلى
> **< ٣٠٪** (كانت > ٧٠٪) — الأصحّ منطقيّاً: نسبة منخفضة في المحور = خطر أعلى.

### تصنيف النضج (دليل الملف — يوحّد `MaturityLevel.minPct`)
| النسبة | التصنيف | الرمز |
|---|---|---|
| ≥ ٧٠٪ | ناضج / جيّد | 🟢 |
| ٤٠–٦٩٪ | متوسّط | 🟡 |
| ٢٠–٣٩٪ | ناشئ | 🟠 |
| < ٢٠٪ | ضعيف / خطر | 🔴 |

**نطاق «مراقبة» ٤٠–٥٠٪:** ليس فتحاً ولا أماناً — حالة وسطى تُعرض كتنبيه.

### مصالحة مقترحة للقمرة (بلا نسخ أعمى)
- القمرة تفرّع على **النضج الكلّيّ** (routing) كما هي.
- عتبات الملف تُنقل كـ**depth-unlock لكل محور** (منفصلة عن الـrouting) — لاحقاً مع الدرجة ٢.
- لا تُرمَّز عتبة واحدة (٤٠٪) مكان تعدّد العتبات.

## §ب — خريطة عمود→حقل (خطة ٩٠ يوم → Initiative / Project / Task)

عمود-بعمود، مطابق لحقول المشروع القائمة (بما فيها `cost` المُضاف):

| عمود الملف | الحقل في StartX | ملاحظة |
|---|---|---|
| المحور | `initiative.source` / وسم | من أيّ محور نضج انبثقت |
| الإجراء | `task.title` (أو `initiative.title`) | فعل مباشر |
| المسؤول | `task.owner` | نصّ حرّ (datalist الجهات) |
| الموعد (اليوم N) | `task.dueDate` / `project.endDate` | **تحويل اليوم النسبي → تاريخ مطلق** (بداية + N) |
| التكلفة التقديريّة | `initiative.cost` | الحقل المُضاف سابقاً ✅ |
| النتيجة المتوقّعة | ملاحظة في `task.description` / `initiative.description` | serializeBody note |
| الحالة | `task.status` | لم يبدأ→`todo` · قيد التنفيذ→`in_progress` · مكتمل→`done` · متأخر→`blocked` |
| المرحلة | دلو أولويّة/زمن | ١-٣٠ عاجل→`critical` · ٣١-٦٠ مهم→`high` · ٦١-٩٠ مستقبلي→`medium` |

**المولّد المؤجَّل (spec):** من نتائج التقييم → لكل محور ضعيف، أنشئ إجراءات المرحلة
المناسبة (حرج→ط١، متوسّط→ط٢، تحسين→ط٣) بالحقول أعلاه. يعيد استخدام `createInitiative`/
`createProject`/`createTask` + منطق التواريخ في `owner/ProjectsPage.tsx`.

## §ج — الأسئلة القاتلة (تتجاوز النسبة → المحور «حرج» مهما كانت %)

من قسم «تنبيهات حرجة تتجاوز النسبة». كلٌّ 🔴، وتقلب المحور إلى حرج فوراً.
النسخة الثانية تميّز **درجتين**: **(قاتل)** = يقلب المحور لصفر/يوقف النشاط ·
**(تنبيه حرج)** = يرفع لحرج بحدّة أقلّ. التصنيف أدناه في عمود «الدرجة».

| السؤال القاتل | الدرجة | المحور | سؤال الدرجة ١ | الخطر السعوديّ |
|---|---|---|---|---|
| موظف بلا تأمين صحّي | 🔴 حرج | الامتثال | q1 | غرامة ١٠٬٠٠٠/موظف |
| عقود غير مسجّلة في التأمينات | 🔴 حرج | الامتثال | q2 | سجن + غرامة |
| رواتب غير مرفوعة عبر «مدد» | 🔴 حرج | التكلفة/الامتثال | q9 | غرامة + إيقاف |
| إقامات تنتهي قريباً | 🔴 حرج | الخطر | q1 | كارثة/كل واحدة |
| رخص عمل غير سارية | 🔴 حرج | الخطر | q2 | غرامة + إيقاف |
| شكاوى موظفين مفتوحة | ⚠️ تنبيه حرج | الخطر | q5 | نزاعات |
| استقالات مفاجئة (٣ شهور) | ⚠️ تنبيه حرج | الخطر | q6 | نزيف |
| غرامات حكوميّة معلّقة | ☠️ **قاتل** | الخطر | q9 | تجميد نشاط |
| موظفون «شبح» مسجّلون | ☠️ **قاتل** | الخطر | q10 | غش + غرامة |

**سابقة إعادة الاستخدام:** `ComplianceAuditProPage.tsx:159` يطبّق نفس النمط
(ترخيص منتهٍ → المحور = صفر + غرامة) — يُقتبَس منه منطق «القلب إلى حرج».

## خارطة التنفيذ المرحليّة (حين تُغلق الأنصاف)
1. **م١** ترقية محتوى `hrMaturity.ts` للمحاور الـ٥ + حقل `risk` اختياريّ في المحرّك.
