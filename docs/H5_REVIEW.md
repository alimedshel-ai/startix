## كيف تُقرأ النسبة والشارة (للتحقّق البصريّ)
- **نسبة القسم** = `sectionScore ÷ sectionMax × 100`؛ `sectionMax = ١٠ × عدد أسئلة القسم` (أقصى خيار = ١٠). **«جزئياً» = ٥ = نصف نقطة السؤال** (نعم=١٠/جزئياً=٥/لا=٠). غير المُجاب = صفر. المصدر: `maturityEngine.ts` (`sectionScore`/`sectionMax`).
- **شارة القسم `X/Y`** = **عدد المُجاب / عدد أسئلة القسم** (لا «الناجح»). فـ«١٠/١٠» = أجبتَ ١٠ من ١٠. المصدر: `MaturityAssessment.tsx:90` (`{answered}/{section.questions.length}`).
